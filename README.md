# cinnamon-dynamic-workspaces
## Install

1. Download `dynamic-workspaces@local.zip` from the [Releases page](https://github.com/Vivek10sharma/cinnamon-dynamic-workspaces/releases/latest)
2. Open a terminal in your Downloads folder and run:
   ```bash
   unzip dynamic-workspaces@local.zip -d ~/.local/share/cinnamon/extensions/
   ```
3. Open **System Settings → Extensions**
4. Tick **Dynamic Workspaces**
5. If it doesn't appear, restart Cinnamon with `Ctrl+Alt+Esc`
